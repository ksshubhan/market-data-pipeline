Definitions

  A negative test gives bad input to correct code. A negative control
  gives the suite's normal input to deliberately broken code, to show
  the suite can fail. This file is about controls. test_capture_file's
  corrupt-one-field cases are negative tests and do not count as
  controls.

  Criterion: a suite has a demonstrated negative control when every
  property its README entry claims has at least one mutation that makes
  the suite exit non-zero with the predicted FAIL message.
  Deterministic mutations are run once. Scheduling-dependent mutations
  are run N times, N fixed below, and reported as a fire count.

  Every mutation stays defined behaviour. An out-of-bounds index into
  std::array is undefined, so whether the suite catches it is not a
  measurement. This is the same reason the relaxed queue was removed
  from A1.

What this shows

  Five of the six properties the README claims have a mutation the
  suite catches: FIFO order, capacity, rejection when full, wrapped
  slot indices, and close reporting completion when closed and empty.

  The sixth does not. With either notify_one deleted, the suite passed
  all 200 runs. The consumer never parked before the push or the close
  reached it, so neither wake path ran. The README's statement that
  this suite covers the condition-variable wake is not supported, and
  by the criterion above test_mutex_queue's negative control is
  demonstrated for five of its six claimed properties, not all six.

Limits

  0 of 100 is an observed count on this machine and build. It bounds
  how often the consumer parks first; it does not show that it cannot.
  The runner matched FAIL messages, not line numbers. The line numbers
  in the predictions, and M8's hang being at the first try_pop, come
  from reading the source.
  M9 and M10 passing say what the suite does not observe. They say
  nothing against the queue itself, which, by reading, signals only on
  the empty to non-empty transition and counts parks.

Consequence

  As fixed by the fallback above, this row closes on this evidence, and
  "the wake test does not force a park" becomes a separately tracked
  item.
